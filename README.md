# Bella Conecta

Archivos listos para publicar con GitHub Pages.

## Publicación
1. Crea un repositorio en GitHub.
2. Sube todos estos archivos a la raíz del repositorio.
3. Ve a Settings > Pages.
4. En Source elige "Deploy from a branch".
5. Selecciona `main` y la carpeta `/ (root)`.
6. Guarda y espera a que GitHub publique el sitio.

El archivo de inicio es `index.html`.

## Instalación en celular
Una vez publicado por HTTPS:
- Android/Chrome: menú del navegador > Instalar aplicación / Añadir a pantalla principal.
- iPhone/Safari: Compartir > Añadir a pantalla de inicio.
